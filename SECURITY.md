# Security

Found a security problem in qu-BETICS? Thank you for looking.

**Please report it privately on Telegram to @degen_manic.** Do not open a public issue for
anything that could put players or funds at risk.

Please include:
- what you found and where (file, endpoint or page),
- the steps to reproduce it,
- what an attacker could do with it.

Rules:
- Test only on your own computer (see the README for running it locally).
- Do not attack, overload or try to access the live services, other players' accounts or funds.
- Give us a reasonable time to fix the problem before you talk about it publicly.

We will reply as soon as we can and tell you when it is fixed.
